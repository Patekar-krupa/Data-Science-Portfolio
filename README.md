Projects

<b>1. Titanic Data Analysis </b>
Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

Key areas:
Data cleaning and preprocessing
Survival analysis based on gender
Age distribution analysis
Relationship between passenger class and ticket fare

Libraries: Python, Pandas, Matplotlib, Seaborn

<b>2. Seaborn Tips Analysis</b>

Data exploration and visualization using the Seaborn Tips dataset.

Key areas:
Average restaurant bills by day
Comparison of tips between smokers and non-smokers
Relationship between total bill and tip amount
Lunch and dinner transaction comparison

Libraries: Python, Pandas, Matplotlib, Seaborn
