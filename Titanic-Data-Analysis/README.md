# Titanic Data Analysis

## Project Overview
An Exploratory Data Analysis (EDA) project using the Titanic dataset to understand passenger demographics, survival patterns and relationships between different variables.

## Objectives
- Analyze survival rates based on gender.
- Explore passenger age distribution.
- Investigate the relationship between ticket fare and passenger class.

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Data Cleaning
- Checked for duplicate records.
- Identified missing values.
- Handled missing age values using median imputation.

## Key Findings
1. Female passengers had a higher survival rate than male passengers.
2. The passenger age distribution was explored to identify the most represented age groups.
3. Ticket fare showed a negative correlation with passenger class encoding, with a correlation value of approximately -0.54.

## Project File
`Titanic_EDA_Analysis.ipynb`

## Conclusion
This project helped explore passenger survival patterns, understand data distributions and identify relationships between variables through Python-based data analysis and visualization.
